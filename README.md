# Hi, I'm Ashiq 👋

B.Tech student in **Artificial Intelligence & Data Science**. I build applied machine-learning systems and test them honestly against simple baselines, from emergency dispatch and trading to computer vision.

🏆 **2nd prize, Abhiyantriki 2026 Quant Challenge** (Somaiya Vidyavihar University, Oct 2026)

## Featured projects

- **[RapidRoute](https://github.com/ashiqhameed/rapidroute)**: ML-driven ambulance placement and shortest-path dispatch for Manhattan. Replayed on 63,806 real EMS calls it never trained on, demand-weighted depots plus learned travel-time routing cut mean response time by **2.4 minutes** and reached **+9.9 percentage points** more calls within 8 minutes. Uses Dijkstra and A\* written from scratch. [Live demo →](https://ashiqhameed.github.io/rapidroute/RapidRoute.html)
- **[GLACIER_GAS Quant Challenge](https://github.com/ashiqhameed/glacier-gas-quant-challenge)**: 2nd-prize team project. Walk-forward-validated direction models and a risk-managed position engine that **made 16.3% while the stock fell 44.9%** in a flash crash (Sharpe 5.84, max drawdown 2.2%). Fully reproducible, with CI.
- **[Aegis-ID](https://github.com/ashiqhameed/aegis-id)**: multi-factor identity verification combining face recognition, voice verification, liveness detection and anti-spoofing, with a risk-based trust score that decides grant / step-up / deny. Built for the Smart India Hackathon internal round.
- **[Adaptive Traffic Signal Controller](https://github.com/ashiqhameed/ai-traffic-signal-controller)**: traffic-signal simulation plus a Q-learning agent that cuts average wait by **12–21%** versus the original heuristic on unseen traffic. [Live demo →](https://ashiqhameed.github.io/ai-traffic-signal-controller/traffic_controller.html)
- **[Patient Feedback NLP Analytics](https://github.com/ashiqhameed/patient-feedback-nlp-analytics)**: Streamlit app applying eight NLP techniques (classification, clustering, topic modelling, aspect-based sentiment, summarisation) to blood-test feedback, routing complaints to the right department.
- **[NYC Airbnb Analysis](https://github.com/ashiqhameed/nyc-airbnb-tableau-analysis)**: interactive Tableau dashboard of ~49k listings, plus a Python price model that beats a simple baseline by ~16%. [Dashboard →](https://public.tableau.com/views/NewYorkCityAirbnb_17768523314010/Dashboard1)
